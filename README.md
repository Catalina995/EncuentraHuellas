# EncuentraHuellas

EncuentraHuellas es una aplicación web desarrollada con Django para facilitar la publicación y búsqueda de mascotas perdidas y encontradas.

## Funcionalidades

- Publicación de avisos de mascotas perdidas y encontradas.
- Carga de imágenes en los avisos.
- Visualización de avisos recientes.
- Búsqueda y filtrado de avisos.
- Vista detallada de cada publicación.
- Diseño responsivo para distintos tamaños de pantalla.

## Tecnologías utilizadas

- Python
- Django
- HTML
- CSS
- SQLite
- Pillow
- Git y GitHub

## Ejecución del proyecto

1. Crear y activar un entorno virtual.
2. Instalar las dependencias:

    pip install -r requirements.txt

3. Aplicar las migraciones:

    python manage.py migrate

4. Iniciar el servidor:

    python manage.py runserver
